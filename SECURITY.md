# Segurança

Este repositório guarda o site do Registro 1367 (arquivos estáticos no GitHub Pages). O jogo roda no itch.io.
Não há servidor, banco de dados, contas ou senhas de jogadores.

## Como reportar uma falha

Achou uma falha de segurança no site, no jogo ou em algo ligado ao projeto? **Não abra uma issue pública.**
Conte em particular por DM no Instagram [@odavyyy1](https://www.instagram.com/odavyyy1/) e espere a correção antes de divulgar.
Não acesse dados de outras pessoas e não explore a falha além do necessário para mostrar que ela existe.
Quem reporta de boa-fé dessa forma não está descumprindo os [Termos de Uso](https://odavyyy.github.io/registro-1367/termos/).
